> Turn boring screenshots into beautiful visuals.

A screenshot beautification tool built with React + Vite + TypeScript.

## Features

- 🎨 12 gradient backgrounds + solid colors
- 🪟 8 window frames (macOS, Browser, Arc, Terminal, iPhone, Android, iPad)
- 📐 12 canvas presets (Instagram, Twitter, 16:9, square, and more)
- 🖱️ Image pan and scale controls
- 💾 PNG export at 1x/2x/3x + clipboard copy
- ✨ Animated fullscreen editor overlay

## Stack

React · Vite · TypeScript · Tailwind CSS · html2canvas
